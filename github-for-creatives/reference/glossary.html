Reference

Glossary

Every term in the course, in plain language, with the videographer analogy that makes it stick. One definition, used the same way in every lesson.

The core four

TermPlain meaningIn your world
Repository (repo)One project: a folder of files plus its full version history.A project folder that remembers every version of itself.
CommitSaving a labeled snapshot of the whole project at a moment.Exporting a named version to your timeline's undo history.
PushUploading your commits from your PC to GitHub (cloud).Syncing your project to the shared drive / backup.
PullDownloading new commits from GitHub down to your PC.Pulling the latest from the shared drive before you work.

Everything else

TermPlain meaning
GitThe engine that does version-remembering, running on your PC.
GitHubThe website (github.com) where repos live in the cloud.
GitHub DesktopThe button-driven app you use instead of the terminal.
CloneMaking your own local copy of a GitHub repo on your PC (with history).
Local vs. remoteLocal = on your PC; remote = the copy on GitHub.com.
Commit messageThe short label you write describing what a snapshot changed.
BranchA safe parallel version where you can experiment without touching the working one.
mainThe default, "real" branch of a repo.
.gitignoreA list of files Git should NOT track (e.g. huge raw video files).
READMEA notes file that explains what a repo is and how to use it.
SkillA reusable packet — instructions (SKILL.md) + prompts + example files — the agent can load.
TerminalThe text-command window. Introduced only in Advanced; optional for a long time.
