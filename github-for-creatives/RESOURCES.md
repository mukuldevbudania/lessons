# Resources

High-trust sources used to ground the lessons. Prefer official GitHub Docs.

## Primary (official)

- **GitHub Desktop docs** — install, clone, commit, push, branch (GUI).
  https://docs.github.com/en/desktop
- **Getting started with GitHub Desktop**
  https://docs.github.com/en/desktop/overview/getting-started-with-github-desktop
- **Creating a commit / committing & pushing changes (Desktop)**
  https://docs.github.com/en/desktop/making-changes-in-a-branch/committing-and-reviewing-changes-to-your-project-in-github-desktop
- **Cloning a repository from GitHub to GitHub Desktop**
  https://docs.github.com/en/desktop/adding-and-cloning-repositories/cloning-a-repository-from-github-to-github-desktop
- **About Git (concepts)**
  https://docs.github.com/en/get-started/using-git/about-git
- **Ignoring files / .gitignore**
  https://docs.github.com/en/get-started/git-basics/ignoring-files
- **Install Git on Windows (for the Advanced terminal lessons)**
  https://git-scm.com/download/win
- **git-scm Pro Git book (free, authoritative)**
  https://git-scm.com/book/en/v2
