Lesson 0008 · Keep It Light Intermediate

.gitignore — Don't Sync the Heavy Stuff

Git is built for text, not 40 GB of RAW footage. A .gitignore file tells it which files to leave alone — essential for a videographer.

This lesson saves you real pain. GitHub rejects huge files and your syncs would crawl. About 8 minutes. Your win: a .gitignore that keeps your prompts and recipes in Git while your giant media files stay out.

1. Why this matters so much for you

Git shines at small text files — prompts, recipes, notes, code. It is bad at giant binary files like .mp4, .mov, .braw, .r3d, project caches. GitHub even blocks files over 100 MB. If you drop a 4K clip into a repo, syncing jams or fails.

In your world Think of Git as your script and shot-list vault, not your media drive. You version the instructions that make the video — the prompts, the recipes — not the heavy exports. The footage lives on your drives and cloud storage; the recipe to recreate it lives in Git.

2. What .gitignore is

A .gitignore is a plain text file at the top of your repo. Each line is a pattern for files Git should pretend don't exist — it won't track them, commit them, or try to sync them. The real files stay on your disk; Git just looks away.

3. Create one

  1. Open your repo folder in Explorer.
  2. Make a new text file named exactly .gitignore — note the leading dot and no .txt on the end. (In Notepad's Save dialog, set "Save as type" to All Files so it doesn't add .txt.)
  3. Paste the patterns below, save.
# Heavy media — keep these OUT of Git
*.mp4
*.mov
*.braw
*.r3d
*.avi
*.mkv

# Big images / exports
*.psd
*.tiff
*.png
*.jpg

# System junk
Thumbs.db
.DS_Store
  1. Back in GitHub Desktop, you'll see .gitignore in Changes. Commit Add gitignore for media files and push.
Test it Drop a .mp4 into the repo folder. Check GitHub Desktop — it should not appear in Changes. Git is ignoring it, exactly as intended. Remove the test file after.
One gotcha .gitignore only ignores files Git isn't already tracking. If you committed a big file before adding the rule, you must remove it from the repo separately. Easiest fix: ask me when it happens — I'll walk you through it.
Primary source Ignoring files — GitHub Docs. Ready-made templates: github/gitignore.

4. Retrieval check

What kind of files does Git handle well, and badly?

Well: small text files like prompts and recipes. Badly: large binary media like video and PSDs.

What does a line in .gitignore do?

It tells Git to ignore matching files — not track, commit, or sync them, though they stay on disk.

Why must the file be named exactly .gitignore?

Git only recognizes that exact name; a trailing .txt makes it an ordinary file Git ignores the rule in.
