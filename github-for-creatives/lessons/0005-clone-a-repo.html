Lesson 0005 · Use Others' Work Intermediate

Clone a Skills Repo

Pull a real public repository — Matt Pocock's agent skills — down to your PC, with its full history, in a couple of clicks.

This is a core mission goal: getting other people's skills onto your machine so you can use and learn from them. The action is called cloning. About 8 minutes. Your win: mattpocock/skills sitting in a folder on your PC, ready to open.

1. What "clone" means

Clone = make your own complete local copy of a repository that lives on GitHub.com. Not just the files — the whole thing, including its version history. It's the read-direction cousin of what you did in Lesson 0004.

In your world Like copying an entire shared project — bins, versions and all — from the studio drive onto your own workstation so you can work with it locally. The original on GitHub.com stays put; you just get your own copy.

2. Clone it with GitHub Desktop

  1. In GitHub Desktop: File → Clone repository, then switch to the URL tab.
  2. In the box, paste: https://github.com/mattpocock/skills
  3. For Local path, pick where it should land — e.g. Documents\github. Click Clone.
  4. Wait a few seconds while it downloads. When it finishes, the repo is open in GitHub Desktop.
The path: File → Clone repository → URL tab → paste the link → Clone.

3. Look at what you got

  1. Click Show in Explorer to open the folder on your PC.
  2. Open the skills/ folder. Each sub-folder is one skill — inside you'll find a SKILL.md (the instructions) and supporting files.
  3. Open a SKILL.md in Notepad or VS Code and read it. This is exactly the shape your own skills will take later (Lesson 0011).
Why this repo mattpocock/skills is public, MIT-licensed ("hack around with them, make them your own"), and well-organized — a clean model of what a good skills library looks like. Read its README.md and GLOSSARY.md too.
Clone vs download ZIP GitHub's website also has a "Download ZIP" button. That gives you the files but no history and no live link to the repo. Cloning (what you just did) keeps both, so you can pull future updates. Prefer clone.
Primary source Cloning a repository from GitHub to GitHub Desktop.

4. Retrieval check

What does cloning give you that downloading a ZIP does not?

The full version history and a live link to the repo, so you can pull future updates.

Inside a skill folder, what file holds the instructions?

SKILL.md — the markdown file describing what the skill does and how to use it.

Does cloning change the original repo on GitHub.com?

No. You get your own local copy; the original stays exactly as it was.
