Lesson 0010 · Demystified Advanced

Meet the Terminal

The same clone, commit, and push you already know — now as typed commands. You've earned this: the ideas are familiar, only the surface is new.

The terminal looks scary but it's just a place to type the four words. We wait until now on purpose, so the commands name things you already understand. About 12 minutes. Your win: you clone a repo and make a commit entirely from the command line, once, so it's no longer a mystery.

You don't have to switch GitHub Desktop stays perfectly valid forever. This lesson is about removing fear, not replacing your workflow. Many pros happily stay in the GUI. The terminal just unlocks power tools later.

1. Install Git for Windows

GitHub Desktop bundled Git invisibly; to use it in a terminal, install the standalone Git for Windows, which includes a terminal called Git Bash.

  1. Go to git-scm.com/download/win and run the installer.
  2. Click Next through the defaults — they're sensible. Finish.
  3. Open the Start menu, type Git Bash, press Enter. A black window with a blinking cursor appears. That's the terminal.

2. Three navigation commands first

TypeMeans
pwd"Where am I?" — prints the current folder
ls"What's here?" — lists files in this folder
cd foldername"Go into" that folder (cd .. goes up one)
In your world The terminal is just a text way to walk through folders — the same folders you see in Explorer, without the icons. cd is double-clicking a folder; ls is looking at what's inside.

3. The four words, as commands

Navigate into a working folder first (e.g. cd Documents/github), then:

Desktop buttonTerminal command
Clone repositorygit clone https://github.com/mattpocock/skills
(see what changed)git status
Stage a file to commitgit add filename.txt
Commit to maingit commit -m "Add my prompt"
Push origingit push
Pull origingit pull

That's it. Same four words, same meanings. -m just means "here comes the message," the Summary box you typed before.

4. Do it once, start to finish

  1. cd Documents/github — go to your github folder.
  2. git clone https://github.com/mattpocock/skills — clone, from the command line this time.
  3. cd skills then ls — step in and look around.
  4. In your own my-prompts: edit a file, then git add . → git commit -m "Edit from terminal" → git push.
git add . — what the dot means The . means "all changed files in this folder." It's the quick way to stage everything at once before a commit.
Primary source The free, authoritative book: Pro Git — Git Basics.

5. Retrieval check

What is the terminal command to clone a repo?

git clone followed by the repository's URL, for example git clone https://github.com/user/repo.

What does the -m in git commit -m "..." do?

It supplies the commit message inline — the same text as the Summary box in Desktop.

Do you have to abandon GitHub Desktop now?

No. The terminal is an extra tool; Desktop remains valid for everything you do.

👩‍🏫 The terminal is no longer a black box — it's just the four words, typed. You now have both tools. Next is the big one you've been building toward: authoring your own skill — prompts, files, and a SKILL.md — and versioning the whole thing in Git.
