Lesson 0002 · Setup Beginner

Install GitHub Desktop

One app, on your Windows PC, with buttons for everything. No terminal — not now, maybe not for weeks.

You already have a GitHub account, so we skip sign-up. Today you install GitHub Desktop and sign in. About 8 minutes. Your win: the app is open, your account is connected, and you're ready to make your first repository next lesson.

Why Desktop, not the terminal GitHub Desktop does cloning, saving versions, and syncing to the cloud — all with buttons and a visual view of what changed. It's the right home base for a creative. We'll meet the terminal much later (Lesson 0010), on purpose, once the ideas are second nature.

1. Download it

  1. In your browser, go to desktop.github.com.
  2. Click the big Download for Windows button. A file named something like GitHubDesktopSetup-x64.exe lands in your Downloads folder.
  3. Double-click that file. Windows installs it and opens GitHub Desktop automatically — there's no "next, next, finish" wizard to fight.
If Windows warns you Windows may show a blue "Windows protected your PC" box (SmartScreen) because it's a fresh download. GitHub Desktop is made by GitHub (owned by Microsoft) and is safe. Click More info → Run anyway. This is normal for any newly downloaded installer.

2. Sign in to your account

  1. When the app opens, click Sign in to GitHub.com.
  2. Your browser pops open asking you to authorize GitHub Desktop. Since you're already logged in to GitHub, click Authorize.
  3. The browser hands you back to the app. You'll see your username in the top area — you're connected.
The path you just walked: GitHub Desktop → Sign in to GitHub.com → browser Authorize → back to the app, signed in.

3. One tiny bit of setup it asks for

The app asks you to confirm your name and email. This isn't a login — it's the label stamped on every version you save, so your history reads "saved by [your brother's name]." Confirm it and continue. If it offers to send usage stats, that's your choice; it doesn't affect anything you'll do.

In your world This is like setting your name in your editing software's project credits — it's just so the history knows who made each change. Set once, forget forever.

4. What you should see now

A mostly-empty GitHub Desktop window with three big options in the middle: Clone a repository, Create a new repository, and Add an existing folder. Don't click them yet — that's the next two lessons. If you see this screen, you're done. ✅

Primary source GitHub's official walkthrough, with current screenshots: Getting started with GitHub Desktop.

5. Retrieval check

Where do you download GitHub Desktop from?

From the official site, desktop.github.com, using the Download for Windows button.

Why did Windows show a warning, and was it a problem?

SmartScreen flags freshly downloaded installers; GitHub Desktop is made by GitHub and is safe to Run anyway.

What are the name and email used for in the app?

They label every saved version with who made it — not a second login, just the history's author stamp.
