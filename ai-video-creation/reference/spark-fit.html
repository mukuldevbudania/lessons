Does It Fit the Spark?

Every model this course recommends, checked against your DGX Spark. The rule: it must FIT, and you must know whether it's fast or a batch job.

The Spark in one paragraph

Your DGX Spark has 128 GB unified memory — far more than any consumer GPU (an RTX 5090 has 32 GB). So models that rule out gaming cards still load fine here. The constraint is bandwidth (~273 GB/s): weights move slowly, so big models fit but run slowly. That single fact is why this course is built around cheap stills first and overnight batching for anything heavy.

Read the two columns separately. Fit = does it load in 128 GB (almost always yes). Speed = interactive vs batch-overnight. Nothing in this course fails the fit test; plan your time around the speed column.

Two gates, always, before you adopt any model: (1) Fit — on the Spark this is nearly always yes; the real question is batch-vs-interactive. (2) License — a brand ad is commercial, so the weight's own card must allow it. A model can pass the hardware gate and still fail the licensing gate (FLUX.1 [dev], Qwen-Image-2.1, Wav2Lip). Both must be green.
