# Lessons

Short, hands-on courses — each lesson is a single styled page that ends with one concrete result.

**Live site:** [mukuldevbudania.github.io/lessons](https://mukuldevbudania.github.io/lessons/)

## Courses

- [GitHub for Creatives](https://mukuldevbudania.github.io/lessons/github-for-creatives/) — from "never opened a terminal" to running your own version-controlled skills library.
- [AI Brand-Ad Course](https://mukuldevbudania.github.io/lessons/ai-video-creation/) — make a cinematic brand ad on a DGX Spark using commercial-safe open models.
- [YouTube for Developers](https://mukuldevbudania.github.io/lessons/youtube-for-developers/) — from "never made a video" to running a channel: plan, record, edit, publish, and grow.
